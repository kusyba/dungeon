# Dungeon Challenge

Решение тестового задания для компании YADRO.

## Описание

Программа симулирует прохождение игроком подземелья. Игрок перемещается по этажам, сражается с монстрами и боссом. Программа обрабатывает события из файла и выводит итоговый отчёт.

## Требования

- Go 1.22 или новее

## Установка и запуск

```bash
# Клонирование репозитория
git clone https://github.com/ВАШ_НИК/dungeon-challenge.git
cd dungeon-challenge

# Запуск программы
go run cmd/dungeon/main.go -config config.json < events.txt

# Запуск тестов
go test -v ./test/...
